# protocol-v1 r5 正式实现基线确认

日期：2026-10-08  
确认方：本机 Codex  
范围：离线协议复验与实现基线确认，不是部署授权或安全验收。

## 确认结论

确认 protocol-v1 r5、包内三份 schema、acceptance-v1 r4 及配套安全边界文档作为正式实现基线。此前六项设计决定及实施约定继续有效。本轮设计评审结束，后续进入模拟实现。

## 本机复验证据

- 包内 SHA256SUMS 覆盖的 55 个文件，55/55 校验值匹配。
- 已核对编码和 F1–F3 对应代码及回归测试。
- 在 Windows 本机执行未修改的包内 tests/run_all.py，开启默认编码告警并将 EncodingWarning 视为错误，退出码为 0；无需用 UTF-8 模式掩盖默认编码问题。
- 跨字段语义：22/22 通过。
- 状态机：34/34 通过。
- Schema：本机缺少 jsonschema，6 项明确跳过。VPS 报告的 schema 6/6、31 个样例和 64 个反例作为 VPS 侧验证记录，本机不宣称独立复验通过。
- 真实部署验收未执行；本机 Worker 未连接 VPS。

## 问题关闭

- 编码：文件读取显式使用 UTF-8，编码告警模式下相关测试通过。
- F1：矛盾执行终态对应 outcome_mismatch，进入交付失败，原执行终态不被覆盖。
- F2：任务定义不可用时未知字段可同时为 null；先建立尝试再下载，失败可以归属到同一尝试。
- F3：重复条目及隐式父目录大小写冲突有真实 tar 回归测试；允许符合规则的显式目录补充条目。

## 冻结后的协作

VPS 方以此实现 publish、ingest、netcheck、renderctl 及模拟测试。本机方以此实现 Worker、渲染适配器和本机独立验证。冻结不表示这些程序已经存在，也不表示实际环境已具备运行条件。

不再为一般改进开启设计评审。基线缺陷需附复现输入和失败测试，以 r5.x 补丁及回归测试处理；其他改进列为实现待办。

账户、安装、网络、防火墙及服务部署按用户后续授权执行。双机接入前完成已约定的隔离和部署验收。隐私前提不变：本机公网 IP 不通过连接或回传内容进入 Anthropic；交接统一称本机，不披露地区、真实端点或用户路径。
